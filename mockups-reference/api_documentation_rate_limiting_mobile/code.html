Authentication

Secure your API requests using Bearer tokens. Include your API key in the Authorization header of every request.

GET /v2/bids/{bid_id}

Retrieves the details of a specific bid by its unique identifier.

curl -X GET "https://api.bidpulse.com/v2/bids/bid_12345" \ -H "Authorization: Bearer YOUR_API_KEY"
